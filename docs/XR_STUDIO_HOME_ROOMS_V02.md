# Domistika XR · Studio Home and Focused Rooms

The new first-run scene is a four-choice Studio Home, instead of four overlapping 3D tool decks. This is a non-destructive navigation and presentation layer, not a new save format or a new repository.

Desktop: Click a studio room tile or press keys 1, 2, 3 or 4. Press H to return Home. Existing OrbitControls still use left-drag to rotate the view on empty space, right-drag to pan and mouse wheel to zoom.

Quest: Enter immersive XR, aim the controller ray at a large Home tile and pull the trigger. A small in-world Studio Home button returns to the room picker. Hand-pinch input and physically anchored portals are outside this rung.

The Canvas Studio shows an easel, painting palette and only the selected editable 2D canvas. 3D Painting shows spatial strokes and the airbrush deck. Sculpture shows 3D workshop objects and the relocated paged deck. Gallery temporarily arranges existing canvases in an arc without saving those display positions. Show advanced tools restores all preexisting sidebar editors.

Artist Easel, spatial painting, workshop model, import/export, localStorage save keys and schema validation remain unchanged.

## Field test

1. Reload on desktop, choose each room and confirm irrelevant decks are hidden.
2. Paint on a selected canvas, switch rooms, return and verify the stroke is intact.
3. Draw a spatial stroke, enter Sculpture, then go back and verify the stroke.
4. Enter Gallery, export or save the 2D scene, and verify serialized original canvas positions.
5. Expand Advanced tools to confirm existing actions still work.
6. In Quest 3 or 3S, test large room tiles and Home button using controller trigger in VR and MR.
7. Confirm comfortable deck spacing and visibility with both standing and seated play.

This release is not a physical-room environment or a teleport locomotion system. Controller comfort and headset input require real headset validation.
